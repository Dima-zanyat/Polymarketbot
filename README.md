# Анализатор лидерборда Polymarket

Анализатор отбирает трейдеров из лидерборда по торговой статистике и помогает найти кандидатов для дальнейшего изучения и копирования сделок.

## Фильтры

Трейдер проходит отбор, если:

- количество сделок — от 6 до 19 999;
- общий `trade_pnl` — не менее 5 000 USDC.

**PnL** — показатель прибыли или убытка. Фильтр по отношению прибыли к торговому объёму отключён.

## Винрейт

Для оценки винрейта нужно учитывать позиции по рынкам с подтверждённым окончательным результатом, включая непроданные проигрышные позиции.

Статус позиции `OPEN` или `CLOSED` сам по себе не подтверждает завершение рынка. Позиции по ещё не разрешённым рынкам не должны попадать в итоговый винрейт.

> Проверка разрешения рынков обсуждена, но её реализация в анализаторе пока не подтверждена.

## Настройки

```python
from decimal import Decimal

MIN_TRADES = 5
MAX_TRADES = 20_000
MIN_TRADE_PNL_USDC = Decimal("5000")
```

Границы количества сделок строгие: ровно 5 и ровно 20 000 не проходят. Порог прибыли включительный: ровно 5 000 USDC проходит.

## Ограничения

- Анализатор оценивает статистику, но не отправляет торговые ордера.
- Для полной истории необходимо получать все страницы данных.
- Высокий общий PnL не означает доходность капитала 30%: исходный капитал в предоставленной статистике отсутствует.
- Результаты отбора — кандидаты для проверки, а не гарантия будущей прибыли.
